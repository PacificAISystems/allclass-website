# All Class Driving Academy Ltd. — Website

Marketing landing page for All Class Driving Academy Ltd., a Class 1 & Class 3
truck driver training school in Edmonton, Alberta.

## Highlights

- **Single-file site** — `index.html` contains all markup, CSS, and JavaScript.
  No build step, no dependencies, no external requests (fonts and icons are
  system/inline).
- **Animated hero** — Canvas-drawn night highway with perspective road, moving
  lane dashes, twinkling stars, and approaching headlights. Respects
  `prefers-reduced-motion`.
- **Light theme** — warm white base, deep navy headings/sections, fleet-red
  accents matching the school's truck livery.
- **Conversion-focused sections** — programs, Alberta MELT pathway, 5.0★ Google
  reviews (1,075+), why-us, four-step enrolment, Amazon Career Choice funding,
  FAQ accordion, contact.
- **Mobile-first details** — sticky call bar, hamburger nav, responsive grids.
- **SEO** — meta description, Open Graph tags, and JSON-LD `AutomotiveBusiness`
  schema with aggregate rating.

## Development

Open `index.html` in a browser, or serve it:

```sh
python3 -m http.server 8000
# → http://localhost:8000
```

## Deployment

Any static host works (Vercel, Netlify, GitHub Pages, Cloudflare Pages).
The site is a single HTML file with zero external dependencies.
